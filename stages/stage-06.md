# 06. 흩어진 조각

- 힌트: (스테이지 자체 힌트 없음, 화면에 `EXIT-` 접두어와 물음표만 표시)

## 관찰

화면 제목 아래 "????" 와 "EXIT-"라는 텍스트가 보인다. 전체 코드 중 앞부분(`EXIT-`)만 화면에 있고 나머지가 비어 있는 모양이다.

## 확인 과정

Application 패널의 Session Storage를 열어보면 `sys_fragment`라는 키가 있고 값은 `FFFF`다.

화면에 보이는 접두어 `EXIT-`와 세션 스토리지에 남아있는 나머지 조각 `FFFF`를 그대로 이어 붙이면 완전한 코드가 된다. 코드 자체가 "화면 절반 + 스토리지 절반"으로 물리적으로 나뉘어 있던 단계였다.

## 코드

`EXIT-FFFF`
