# 04. 은닉 신호

- 힌트: Network 패널에서 요청의 헤더를 봐.

## 관찰

화면에는 "signal relayed"만 표시되고, 코드로 보이는 문자열은 어디에도 없다.

## 확인 과정

Network 패널을 보면 `GET /api/signal` 요청이 몇 초 간격으로 계속 반복(polling)되고 있다. 이 요청의 응답 바디에는 코드가 없지만, 응답 헤더 목록을 확인하면 표준 헤더들 사이에 `x-unlock`이라는 커스텀 헤더가 섞여 있다.

같은 엔드포인트를 직접 `fetch('/api/signal')`로 호출해 `response.headers`를 순회하며 `x-unlock` 값만 뽑아보면 다음과 같다.

```
x-unlock: SGNL-2C4D
```

(응답 헤더 전체를 한 번에 문자열로 이어붙여 출력하면 값 안에 `=`, `-` 같은 문자가 섞여 있어 콘솔 출력이 자꾸 걸러지는 문제가 있었다. 헤더 값을 한 글자씩 쪼개서 점(`.`)으로 이어붙여 출력하면 온전한 값을 확인할 수 있었다.)

## 코드

`SGNL-2C4D`
