# 01. 멈춘 부팅

- 힌트: F12로 개발자도구를 열고 Elements 패널을 봐.

## 관찰

로그인 직후 이동한 `stage/1` 화면에는 회전하는 스피너와 "SYSTEM BOOTING... 99%" 문구만 계속 떠 있다. 진행률이 99%에서 멈춘 채 움직이지 않는다.

## 확인 과정

로딩 스피너는 화면 위에 얹힌 오버레이일 뿐, 그 아래 실제 페이지는 이미 완성된 상태로 렌더링돼 있었다. Elements 패널로 DOM 트리를 그대로 훑어보면 오버레이 뒤에 다음 내용이 이미 존재한다.

```
heading "01"
generic "BOOT SEQUENCE COMPLETE"
generic "BOOT-7F2A"
form
  textbox "코드 입력"
  button "제출"
generic "힌트"
  generic "F12로 개발자도구를 열고 Elements 패널을 봐."
generic "SYSTEM BOOTING... 99%"   <- 화면에 보이는 오버레이
```

즉 코드(`BOOT-7F2A`)는 처음부터 화면에 그려져 있었고, 그 위를 스피너가 가리고 있을 뿐이었다. 다만 오버레이가 클릭 이벤트까지 가로채기 때문에, 마우스로 입력창을 클릭하고 버튼을 눌러도 오버레이가 클릭을 먹어버려 제출이 되지 않는다. 이 경우 입력 필드의 value를 코드로 직접 설정하고 그 값이 들어있는 `<form>`을 스크립트로 바로 제출(submit)하면, 화면 클릭을 거치지 않고도 같은 제출 요청이 서버로 나간다.

## 코드

`BOOT-7F2A`
